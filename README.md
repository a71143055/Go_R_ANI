# Go_R_ANI — 바둑 게임방

바둑과 오목을 **앱에 내장된 자체 AI**와 둘 수 있는 웹 앱입니다. 외부 AI 서비스나 API 키, 인터넷 연결이 필요 없습니다.
화면을 보지 않고도 끝까지 둘 수 있도록 좌표 입력, 키보드 조작, 스크린리더 안내를 지원합니다.

| 게임 | 내용 |
|---|---|
| **바둑** | 9·13·19줄. 패·자충수 규칙, 중국식 계가, 자동 사석 판정, 무르기·기권 |
| **맹기 바둑** | 판에 돌이 보이지 않는 바둑. "맹기"(수순 공개) / "완전 맹기"(수순도 숨김) |
| **오목** | 15줄, 5목 이상이면 승리 (자유 룰) |

## 구조

```
브라우저 (server/wwwroot: HTML/JS — 그리기, 입력, 음성 안내)
   │  HTTP JSON
   ▼
C# ASP.NET Core 서버 (server/)
   ├─ 게임 세션 관리, API 엔드포인트          Games.cs, Sessions.cs
   └─ Rust 엔진 호출 (P/Invoke)               Engine.cs
         │  C ABI: engine_call(json) / engine_free(ptr)
         ▼
Rust 엔진 (engine/, cdylib)
   ├─ go.rs       바둑 규칙: 착수·따내기·패·자충수·계가
   ├─ go_ai.rs    바둑 AI: MCTS + RAVE, 멀티스레드, 사석 판정, 수 해설
   ├─ omok.rs     오목 규칙: 승리 판정, 5목 위협 지점
   └─ omok_ai.rs  오목 AI: 알파-베타 반복 심화 탐색
```

## 자체 AI

- **바둑**: 몬테카를로 트리 탐색(MCTS)과 RAVE를 씁니다. 탐색에는 따내기·단수 살리기·자충 회피 같은 전술 지식을 넣었습니다. CPU 코어 수만큼(최대 8개) 스레드가 각자 트리를 키운 뒤 결과를 합칩니다. 8스레드 기준으로 9줄은 초당 약 23만 판, 19줄은 초당 약 6만 판을 시뮬레이션합니다.
- **종국 사석 판정**: 종국 판면에서 대국을 수천 번 끝까지 두어 보고, 각 돌이 상대 소유가 되는 확률로 사석을 판정합니다.
- **오목**: 5칸 창 평가와 알파-베타 탐색을 씁니다. 공격·수비 가치로 후보 수를 정렬하고, 상대의 5목 위협이 있으면 막는 수만 봅니다.
- 매 수마다 AI가 해설을 붙입니다(따냄, 단수, 응수, 4 막기 등). 바둑은 예상 승률과 예상 진행도 보여 주는데, 맹기 대국에서는 예상 진행을 숨깁니다.
- 상단의 **AI 생각 시간**(빠름/보통/깊게/아주 깊게)을 늘릴수록 AI가 강해집니다. 바둑은 수당 1/3/8/15초, 오목은 0.3/1/3/6초입니다.

## 실행

필요한 것: .NET SDK 10, Rust(cargo)

```bash
./run.sh      # Rust 엔진 빌드 + C# 서버 실행
```

브라우저에서 <http://localhost:5000> 을 엽니다. `dotnet build`만 해도 C# 빌드 전에 Rust 엔진이 자동으로 빌드되어 출력 폴더로 복사됩니다.

## 화면을 보지 않고 두기 (접근성)

- **좌표 입력**: `D4`처럼 입력하고 Enter를 누릅니다. 바둑은 `pass`로 패스합니다.
- **키보드**: 판에 초점을 맞추고 방향키로 이동한 뒤 Enter나 Space로 둡니다. 이동할 때마다 좌표와 그 자리 상태(빈 점/흑 돌/백 돌)를 읽어 줍니다. 맹기 대국에서는 좌표만 읽습니다.
- **자동 안내**: 내 수, AI 수와 해설, 따낸 돌, 결과가 스크린리더로 자동으로 읽힙니다(aria-live).
- **판 읽기**: 현재 판의 흑·백 돌 위치를 전부 읽어 줍니다. 맹기 대국 중에는 쓸 수 없습니다.
- **오목 위협 경고**: AI가 둔 뒤 다음 수로 5목이 되는 자리가 있으면 알려 줍니다.
- 좌표: 열은 왼쪽부터 A~T(I는 쓰지 않음), 행은 아래쪽이 1입니다.

## 맹기 바둑

- **맹기**: 판에 돌이 보이지 않습니다. 직전 수만 1.5초 동안 표시되고, 오른쪽에 수순 목록이 나옵니다.
- **완전 맹기**: 수순 목록도 숨기고 직전 수의 좌표만 알려 줍니다.
- 대국 중에는 서버가 판 정보를 가려서 보냅니다. "엿보기" 버튼을 누르고 있는 동안만 판이 보이고, 엿본 횟수가 기록됩니다.
- 종국(양쪽 패스) 후에는 판이 공개되고 계가합니다.

## API 요약

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/status` | 엔진 정보 (스레드 수) |
| POST | `/api/go/new` | `{size, komi, humanColor, blind: "off"\|"human"\|"strict"}` |
| POST | `/api/go/{id}/play` | `{move: "D4"\|"pass"}` 사람의 수 |
| POST | `/api/go/{id}/ai` | `{think: "fast"\|"normal"\|"deep"\|"max"}` AI의 수 |
| POST | `/api/go/{id}/score` | 종국 후 사석 판정 + 계가 |
| POST | `/api/go/{id}/undo`, `/resign`, `/peek` | 무르기, 기권, 맹기 엿보기 |
| POST | `/api/omok/new`, `/{id}/play`, `/{id}/ai`, `/{id}/undo` | 오목 |

API는 좌표 문자열(`D4`)로 수를 주고받기 때문에, 로봇 제어 프로그램 같은 다른 클라이언트에서도 같은 방식으로 붙일 수 있습니다.
