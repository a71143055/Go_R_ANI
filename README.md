# Go_R_ANI — 바둑 게임방

바둑판에서 하는 게임 여섯 가지를 **앱에 내장된 자체 AI**와 둘 수 있는 웹 앱입니다. 외부 AI 서비스나 API 키가 필요 없습니다.
시각장애인도 즐길 수 있도록 **음성 입력·음성 안내·키보드 조작·좌표 입력**으로 화면을 보지 않고도 끝까지 둘 수 있게 만들었습니다.

| 게임 | 내용 |
|---|---|
| **바둑** | 9·13·19줄. 패·자충수 규칙, 중국식 계가, 자동 사석 판정. **맹기 바둑**(수순 공개 / 완전 맹기) |
| **따내기 바둑** | 돌을 하나라도 먼저 따내면 승리. 5·7·9줄, 십자 배치 시작 |
| **사활 문제** | 묘수풀이 7문제 (단수·양단수·환격·직삼·곡삼). 정답 판정, 힌트, 다시 풀기 |
| **오목** | 15줄, 5목 먼저 |
| **펜테** | 19줄, 5목 또는 상대 돌 10개(5쌍) 따내기. 양쪽에서 막으면 두 점을 따냄 |
| **육목** | 19줄, 흑 첫 수만 1개, 이후 매 차례 2개씩, 6목 먼저 |

## 구조

```
브라우저 (server/wwwroot: HTML/JS — 그리기, 입력, 음성 입출력, 타이머)
   │  HTTP JSON
   ▼
C# ASP.NET Core 서버 (server/)
   ├─ 게임 세션, API 엔드포인트               Games.cs, Sessions.cs
   └─ Rust 엔진 호출 (P/Invoke)               Engine.cs
         │  C ABI: engine_call(json) / engine_free(ptr)
         ▼
Rust 엔진 (engine/, cdylib)
   ├─ go.rs           바둑 규칙: 착수·따내기·패·자충수·계가
   ├─ go_ai.rs        바둑 AI: MCTS + RAVE, 멀티스레드, 사석 판정, 수 해설
   ├─ atari_ai.rs     따내기 바둑 AI(알파-베타) + 단수 정보
   ├─ tsumego.rs      사활 문제집 + 풀이기(벤슨 삶 판정, 메모이제이션 탐색)
   ├─ linegame.rs     오목·펜테·육목 규칙
   └─ linegame_ai.rs  오목·펜테·육목 AI: 창 평가 + 알파-베타 반복 심화
```

## 자체 AI와 난이도

상단의 **AI 난이도(하·중·상)**에 따라 실력이 실제로 달라집니다.

| 게임 | 하 | 중 | 상 |
|---|---|---|---|
| 바둑 | 0.5초·700판만 읽고, 방문 수에 비례해 무작위로 고름 | 2스레드 2초 | 전체 스레드(최대 8) 6초 |
| 따내기 바둑 | 따낼 수 있으면 따내고, 아니면 상위 후보 4개 중 무작위 | 3수 앞까지 | 3초 동안 최대한 깊게 |
| 오목·펜테·육목 | 이기는 수는 두고, 아니면 상위 후보 3개 중 무작위 | 4수 앞까지 | 3초 동안 최대한 깊게 |

- 사활 문제의 백은 정답 검증 역할이라 난이도와 상관없이 항상 최선으로 응수합니다.
- 매 수마다 AI가 해설을 붙입니다. 바둑은 예상 승률도 보여 주는데, 맹기 대국에서는 예상 진행을 숨깁니다.
- 바둑 AI 속도(8스레드 기준): 9줄 초당 약 23만 판, 19줄 초당 약 6만 판의 시뮬레이션.

## 실행

필요한 것: .NET SDK 10, Rust(cargo)

```bash
./run.sh      # Rust 엔진 빌드 + C# 서버 실행
```

브라우저(크롬·엣지 권장)에서 <http://localhost:5000> 을 엽니다. `dotnet build`만 해도 C# 빌드 전에 Rust 엔진이 자동으로 빌드되어 출력 폴더로 복사됩니다.

## 소리와 키보드로 두기 (접근성)

- **음성 입력**: 🎤 말하기 버튼이나 **Alt+M**을 누른 뒤 말합니다.
  - 좌표: "디 사" → D4, "에이치 팔" → H8, "케이 십" → K10 (알파벳의 한국어 발음 + 한국어 숫자 또는 아라비아 숫자)
  - 명령: "패스", "무르기", "판 읽기", "남은 시간", "힌트", "다시 풀기", "다음 문제", "새 게임", "기권", "다시 말해", "조용"
  - 브라우저 음성 인식(Web Speech API)을 쓰기 때문에 **크롬·엣지에서만 되고 인터넷 연결이 필요**합니다. 음성은 브라우저 제조사의 서버에서 인식됩니다.
- **음성 안내**: 내 수, AI 수와 해설, 따낸 돌, 단수 경고, 5목 위협, 결과, 남은 시간을 앱이 직접 읽어 줍니다(브라우저 음성 합성, 오프라인 가능). 스크린리더를 쓰신다면 겹치지 않게 "음성 안내"를 꺼도 됩니다. 말하기 속도도 고를 수 있습니다.
- **좌표 입력**: 좌표칸에 `D4`나 `디 사`, `패스` 같은 명령을 입력하고 Enter.
- **키보드**: 판에 초점을 맞추고 방향키로 이동, Enter나 Space로 둡니다. 이동할 때마다 좌표와 그 자리 상태(빈 점/흑 돌/백 돌)를 읽어 줍니다(맹기 중에는 좌표만).
- **판 읽기**: 현재 판의 흑·백 돌 위치와 따낸 돌 수를 읽어 줍니다. 맹기 대국 중에는 쓸 수 없습니다.
- **단축키**: Alt+M 음성 입력, Alt+R 마지막 안내 다시 듣기, Alt+T 남은 시간 듣기.
- 좌표: 열은 왼쪽부터 A~T(I는 쓰지 않음), 행은 아래쪽이 1입니다.

## 타이머

상단 "시간 제한": 없음 / 한 수 30초 / 한 수 60초 / 10분 + 초읽기 30초 3회 / 20분 + 초읽기 30초 3회.
내 차례에만 시간이 흐르고, "1분 남았습니다", "초읽기 10초", 마지막 5초 카운트다운을 소리로 알려 줍니다. 시간이 다 되면 시간패입니다.

## 사석함과 로봇 연동

- 화면에 흑·백 **사석함**이 있어 따낸 돌이 쌓입니다(바둑, 따내기 바둑, 펜테).
- 모든 착수 응답에는 **따낸 돌의 좌표 목록**이 들어 있습니다 (사람의 수: `captured`, AI의 수: `ai.captured`). 로봇은 이 목록을 받아 해당 돌을 집어 받침대(사석함)로 옮기면 됩니다.
- 수는 좌표 문자열(`D4`)로 주고받으므로, 로봇 제어 프로그램도 웹 화면과 같은 API로 붙일 수 있습니다.

## 맹기 바둑

- **맹기**: 판에 돌이 보이지 않습니다. 직전 수만 1.5초 동안 표시되고, 수순 목록이 나옵니다.
- **완전 맹기**: 수순 목록도 숨기고 직전 수의 좌표만 알려 줍니다.
- 대국 중에는 서버가 판 정보를 가려서 보냅니다. "엿보기" 버튼을 누르고 있는 동안만 판이 보이고, 엿본 횟수가 기록됩니다.

## 테스트

```bash
cargo test --release --manifest-path engine/Cargo.toml                          # 규칙·AI·사활 문제 검증
cargo test --release --manifest-path engine/Cargo.toml -- --ignored --nocapture  # 바둑 AI 속도 측정
```

사활 문제 테스트는 문제마다 "정답 수로 실제로 목표를 이룰 수 있는지", "아무 데나 둬도 이기는 문제는 아닌지"를 풀이기로 검증합니다.

## API 요약

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/status` | 엔진 정보 |
| POST | `/api/go/new` | `{size, komi, humanColor, blind: "off"\|"human"\|"strict"}` |
| POST | `/api/go/{id}/play` | `{move: "D4"\|"pass"}` 사람의 수 → `captured`, `ataris` |
| POST | `/api/go/{id}/ai` | `{level: "easy"\|"normal"\|"hard"}` AI의 수 → `ai.move`, `ai.captured`, `ai.comment` |
| POST | `/api/go/{id}/score`, `/undo`, `/resign`, `/peek`, `/timeout` | 계가, 무르기, 기권, 맹기 엿보기, 시간패 |
| POST | `/api/atari/new` | `{size, humanColor, cross}` — 이후 `/play`, `/ai`, `/undo`, `/timeout` |
| GET | `/api/tsumego/list` | 사활 문제 목록 |
| POST | `/api/tsumego/new` | `{id}` — 이후 `/play`(백 응수까지 한 번에), `/hint`, `/retry`, `/timeout` |
| POST | `/api/line/new` | `{variant: "omok"\|"pente"\|"connect6", humanColor}` — 이후 `/play`, `/ai`, `/undo`, `/timeout` |
