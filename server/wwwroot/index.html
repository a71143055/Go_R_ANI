엔진 확인 중…

홈

바둑판에서 하는 게임 여섯 가지를 내장된 자체 AI와 즐길 수 있습니다. 인터넷 연결이나 API 키 없이 동작하며, 화면을 보지 않고도 소리와 키보드만으로 끝까지 둘 수 있습니다.

소리와 키보드로 두는 방법

  • 음성으로 두기: 🎤 말하기 버튼이나 Alt+M을 누르고 "디 사"(D4), "패스", "무르기", "판 읽기", "남은 시간", "힌트", "새 게임", "대국 끝내기", "다시 말해", "앱 종료"처럼 말합니다. 크롬이나 엣지에서 되고, 인터넷 연결이 필요합니다.
  • 좌표 입력: 좌표칸에 D4처럼 입력하고 Enter. 명령어("패스", "무르기")도 입력할 수 있습니다.
  • 키보드: 판에 초점을 맞추고 방향키로 이동, Enter나 Space로 둡니다. 이동할 때마다 좌표와 그 자리 상태를 읽어 줍니다.
  • 음성 안내: 내 수, AI 수, 해설, 따낸 돌, 단수 경고, 결과를 앱이 직접 읽어 줍니다. 스크린리더를 쓰신다면 겹치지 않게 "음성 안내"를 꺼도 됩니다. Alt+R은 마지막 안내를 다시 듣기, Alt+T는 남은 시간 듣기, Alt+Q는 앱 종료입니다.
  • 타이머: 내 차례에만 시간이 흐르고, 남은 시간을 소리로 알려 줍니다.
  • 내 기록: 모든 대국은 계정에 자동 저장됩니다. "내 기록"에서 전적을 보고, 진행 중인 대국을 이어서 두고, 지난 대국을 한 수씩 다시 들을 수 있습니다. 음성: "내 기록", "다음", "이전", "로그아웃".
  • AI 난이도: 하·중·상. "하"는 수를 깊이 읽지 않아 실수를 하고, "상"은 전력으로 둡니다. 사활 문제의 백은 항상 최선으로 응수합니다.
  • 좌표: 열은 왼쪽부터 A~T(I는 쓰지 않음), 행은 아래쪽이 1입니다.
